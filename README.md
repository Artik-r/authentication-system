# 🔐 Authentication System

A secure user authentication system built with **Flask** and **SQLite**. The application allows users to register, log in, maintain secure sessions, and log out through a modern glassmorphism user interface.

---

## ✨ Features

- 👤 User Registration
- 🔑 Secure Login
- 🚪 Logout Functionality
- 🔒 Password Hashing
- 🛡 Flask Session Management
- 👁 Show / Hide Password
- 💎 Glassmorphism User Interface
- 🎨 Gradient Background
- 📱 Responsive Design
- ⚡ Flash Messages

---

## 🛠 Tech Stack

- Python
- Flask
- SQLite
- HTML5
- CSS3
- Jinja2
- Werkzeug Security

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Artik-r/authentication-system.git
```

Move into the project

```bash
cd authentication-system
```

Install dependencies

```bash
pip install -r requirements.txt
```

Initialize the database

```bash
python init_db.py
```

Run the application

```bash
python app.py
```

Open your browser and visit

```
http://127.0.0.1:5000
```
